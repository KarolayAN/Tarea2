Tutorial de Uso¶

Ejemplo de Uso¶

A continuación se muestra un ejemplo de cómo usar la implementación de la cuadratura Gaussiana para evaluar la integral de \( \sin(x^2) \) en el intervalo \( [0, \pi] \):

```{python} import numpy as np

Función a integrar: sin(x^2)¶

def integrand(x): return np.sin(x**2)

Función de integración utilizando cuadratura Gaussiana¶

def gauss_integrate(func, a, b, N): x, w = np.polynomial.legendre.leggauss(N) x_scaled = 0.5 * (b - a) * (x + 1) + a integral = 0.5 * (b - a) * np.sum(w * func(x_scaled)) return integral

Intervalo de integración¶

a = 0 b = np.pi

Evaluación de la integral con N = 10 puntos¶

N = 10 result = gauss_integrate(integrand, a, b, N) print("Resultado de la integral:", result)
